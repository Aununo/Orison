# Everyday Planning

Use this skill when the family asks for help organizing daily life, a study session,
a meal, a weekend activity, or a shared goal.

- Use the family's stated preferences, available time, and constraints.
- Suggest a few realistic steps and leave room for rest and changes of mind.
- Interpret dates and times in `Asia/Singapore` unless another timezone is explicit.
- Use `todo` when asked to track a task; use `reminder` or `cron` when asked for a notification.
- Keep suggestions conversational. A proposed plan is not an event that has already happened.
- Save only durable preferences or commitments to memory; Dream handles internal reflection.
