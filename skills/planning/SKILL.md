# Planning

Use this skill when the task has multiple steps, unclear scope, or meaningful sequencing risk.

- Identify the desired outcome first.
- Separate blockers from parallel or follow-up work.
- Keep plans short and executable.
- Include acceptance criteria that can be tested or inspected.
- Update the plan as facts change.
