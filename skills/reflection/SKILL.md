# Reflection

Use this skill for post-task review, learning loops, and Dream-style self-improvement.

- Distinguish stable lessons from one-off details.
- Preserve useful evidence and avoid overfitting to a single event.
- Produce auditable summaries before changing memory or skills.
- Keep suggested improvements narrow and reversible.
