# Coding

Use this skill for implementation, debugging, refactoring, and code review tasks.

- Read the relevant code before changing it.
- Prefer existing project patterns over new abstractions.
- Keep changes scoped to the user request.
- Add focused tests when behavior changes or risk is non-trivial.
- Run the smallest useful verification command before reporting completion.
