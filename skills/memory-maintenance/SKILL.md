# Memory Maintenance

Use this skill when adding, reviewing, or cleaning long-term memory.

- Save durable preferences, stable facts, and repeated project decisions.
- Do not save sensitive secrets, temporary instructions, or contradicted facts.
- Keep entries concise and human-readable.
- Preserve memory fences as context boundaries, not as content to memorize.
